# 审计、放行和交付清单

版本：1.0.0　状态：DOC_AUDIT_PASS

## 1. 审计独立性和版本冻结

每个代码 task 实施完成后按顺序冻结两轮审查：

1. Writer 声明停止写入，记录 target HEAD/base、工作树差异、changed paths、TaskSpec revision、source matrix revision、source/target manifest hashes。
2. Main 确认 writer 任务已 terminal；不存在后台 formatter、build、测试或未提交写入进程。
3. 独立 Source Fidelity sidecar 收到用户原始要求、AGENTS 规则、冻结来源路径/commit/hash、逐项 mapping matrix、frozen diff 和测试结果。它只能检查，不可给作者方案背书，不可编辑或自己写 receipt。
4. 只有 Source Fidelity 对同一 revision 返回 PASS 且同一个 terminal source-role dispatch evidence 绑定后，才可交普通 Audit。
5. 普通 Audit 使用另一个只读身份，检查完整任务 contract、全 diff、source receipt、测试、负例、敏感数据、既有用户改动保留情况。
6. 两个审计必须引用同一 target revision/hash；任何代码/文档/测试变化都使旧 receipt 失效。

审计工具若未返回正式 runtime child ID、terminal event、observed model/effort，则记录 ROUTE_UNVERIFIED；若正式 SourceFidelityReceipt/AuditReceipt 缺失，则不能把评论或终局自述冒充结构化 receipt。不要声称 sandbox 已验证只读；平台运行时目前只观察 model/effort/lifecycle。

## 2. Source Fidelity 逐项判定表

对 02 中每个有代码 diff 的 SF-ID，审计员必须填写：

| 检查项 | 通过条件 |
|---|---|
| source identity | repo/commit/path/symbol/test exact 且 hash 与 frozen manifest 一致 |
| target identity | 当前 target revision、生产入口和变化文件都在冻结 TaskSpec 中 |
| behavior match | 正例证明 source semantics；负例证明超界时 fail-closed |
| changes | 没有未登记的重命名、字段、单位、变量、helper、threshold、fallback、protocol 或另一套算法 |
| explicit differences | 所有薄适配、legacy compatibility 与授权扩展分开列出，不与 source parity 混写 |
| cross path | Runtime、Persistence、Worker、Mock、contract tests 的同语义实现一致 |
| receipts | Source receipt 与 source-role runtime dispatch、同一 manifest/task/revision/diff exact binding 一致 |

返回值仅允许：

- PASS：所有映射和证据均可复核，无未解决 source deviation。
- FAIL：观察到不忠实/越界实现，列文件、符号、源/目标语义和阻断步骤。
- INSUFFICIENT_EVIDENCE：来源不完整、路由不明、输出/测试不足或无法证明；不等于通过。

- 用户目标、AGENTS 与所有上位契约不冲突。
- 每一个修改/新增/删除文件均在 TaskSpec allowlist；工作树原有差异未被覆盖。
- 所有新 symbol/变量/字段/注释/依赖都有 SF-ID/contract owner；无“顺手优化”或无来源行为。

- MusicPlan 单轨完整窗口保持一致；composition fade 映到来源 track；native/SFX 不被假冒为 speech；music_applied 不被误作声学验收。

- ALCHMED1–7 兼容路径未删除且新写入不走自定义 legacy mixer。
- G02/C10/E05/短时长状态登记一处当前权威值，历史状态不被覆写。
- 所有声明 PASS 都有 command/output/exit code/fixtures/source revision；没有遗留 skip/blocked 未披露。
- 没有真实密钥、票据、signed URL、原始 provider response、媒体、数据库 dump、.env*、上游全仓文件、网络、VPS 或部署修改进入 diff。
