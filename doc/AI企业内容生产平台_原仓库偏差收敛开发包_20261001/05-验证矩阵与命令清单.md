# 验证矩阵与命令清单

版本：1.0.0　状态：DOC_AUDIT_PASS_WITH_EXECUTION_BLOCKERS

## 1. 验证总原则

- 测试必须沿实际 production call path 传递同一 source facts；纯 helper fixture 不能单独证明生产链路接通。
- 正例证明支持行为；负例证明超范围、缺证据、错误 owner、错误 profile 和旧版本行为均在副作用发生前阻断。
- 测试可用本地 fixture/fake provider/fake ffmpeg，不得访问真实 Provider、Pixabay、TTS、Veyra、DB生产库、VPS、SSH 或公开网络。
- music_applied 不等于音乐混音成功；静态滤镜图不等于实际听感合格；MarkItDown 单测不等于 runtime image 依赖齐全。
- 每次测试记录命令、退出码、通过/失败/跳过数、依赖版本、环境变量名（不得记录 secret 值）、临时目录和失败复现。

### 3.3 SF-HB-03 时间行覆盖（候选验收规格；当前不得执行/编码）

以下是未来独立 `P2-T` TaskSpec 的验收规格，不是当前 writer 授权。只有 Main 先证明真实输入能唯一绑定一个冻结 Provider segment，且 marker/时长映射不依赖 SF-HB-02 缺失的结构化场景/角色/道具事实，再新建精确 TaskSpec 后才执行。输入对象无法唯一绑定时，整行保持 `SOURCE_DECISION_REQUIRED`，不要先加 parser 或把下面的案例报告为已验证。

最小正例：

- 8 秒：覆盖 [0,8]，3 秒行后按来源覆盖 2 秒尾段；镜头映射不遗漏。
- 9 秒：[0,3]、[3,6]、[6,9] 连续覆盖。
- 15 秒：从 0 到 15 连续覆盖，行顺序与对应子镜头顺序一致。

必测反例：

- 无时间行、起点非 0、终点小于 segment 总时长、超过总时长；
- 行间空隙、交叠、逆序、重复、无效范围、数字/单位解析歧义；
- 镜头 marker 缺失、重复、跳号、多余；某 marker 没有行、多 marker 混成一行或顺序逆转；
- 3 秒分格不符合来源与尾段处理；任何局部范围越出同一个 Provider segment；
- 多个 provider segment 的行编号被错误拼接，造成跨 segment 任务或把镜头行变成额外 Provider task。

所有负例必须证明 semantic plan 在 source validation 不通过，不创建 provider attempt/request id，不写费用/成功事实。

### 3.5 SF-OM-01/02 项目级单曲/fade

必须跨层测试：Persistence → Production Worker encoding → Media Runtime decode/map → OpenMontage full_mix adapter command graph。

| Case | 断言 |
|---|---|
| AUTO 有合格曲目 | 单一 MUSIC asset/track；start=0、end=target；asset identity 在各层一致 |
| MANUAL 有指定曲目 | 仅指定 asset；仍只有单轨覆盖全片 |
| P4 跨层 identity fixture | Persistence → Worker encoder/consumer → Runtime decode/fade 使用同一 MUSIC asset ID `ast_native_manual_music`；各层断言 ID 不变 |
| OFF | 不存在 platform MUSIC track；原生 Provider 音频 owner 原样保留 |
| composition default fade=1500/2500ms、track fade absent | 映射到 OpenMontage source track 1.5/2.5 seconds |
| track 明确覆盖默认 fade | 仅使用该 track 显式值，不被全局默认覆盖 |
| no-fade values | track fade absent 时才映射 composition default；显式 `0` 不生成 fade filter；显式 `null` 在 `.optional()` schema 边界拒绝 |
| two accepted video segments | 不分别选曲、不生成两条不同 MUSIC；final plan 只一条全片曲 |
| music_applied | 单测只断言 asset presence，不用于断言音频听感/滤镜成功 |

测试要断言 source _full_mix 实际收到的 track dict 和 filter graph，而非只断言 Persistence 的 JSON 中仍有一个 music_mix.fade_in_ms 字段。

### 3.6 SF-OM-03 ducking 音轨角色

- 有独立 platform narration bytes + 独立 MUSIC bytes 且 duck enabled：source sidechain graph 被构造，music 仅由独立 speech track 作 key 控制。
- 没有独立 speech bytes（包括只有 Provider/source MP4 音轨）时，不得把其 owner/name 当 speech；不得断言其触发或已应用 narration duck。
- 只有存在独立、来源可证明的 SFX bytes 时才覆盖 SFX 顺序；当前任务不得将整段 Provider MP4 重标成 SFX。
- 反例须确认未额外调用 audio separator、TTS、speech classifier、自造 compressor、owner rewrite 或 legacy mixer fallback。

~~~powershell

~~~

之后跑相关包 typecheck 和 root regressions：

~~~powershell

~~~

若没有 public contract 改动，不运行会重写导出文件的 contracts generation 作为“测试”；先在 diff 确认没有未授权生成物。若已有 ADR 允许合同变化，按该 ADR 运行生成命令并将生成文件纳入精确允许列表。

Python Runtime 从各服务目录执行，并把虚拟环境固定到仓库外、本任务新建的隔离目录。`uv sync` exact-sync 只针对 `$env:UV_PROJECT_ENVIRONMENT` 指定的该新目录；lock 制品从本机当前配置的 uv cache 离线读取，uv 按 lock 校验制品。不得设置 `UV_CACHE_DIR` 到一个新建空目录，也不得清理/覆盖已有 cache。先以 `uv cache dir` 记录当前 cache 路径，再强制 `UV_OFFLINE=1`；如果 locked artifact 缺失，记录 `BLOCKED_LOCAL_CACHE` 并停止，不在本任务中联网。只有新任务明确授权下载锁定依赖后，才可把 cache 设为该任务新建目录、临时关闭 offline 执行 `uv sync --locked`，下载完成立即恢复 offline 并记录 package source/hash。`UV_PROJECT_ENVIRONMENT` 与 `UV_OFFLINE` 是 uv 官方支持的环境变量；见 [uv project sync](https://docs.astral.sh/uv/concepts/projects/sync/) 与 [uv environment variables](https://docs.astral.sh/uv/reference/environment/)。

~~~powershell
$repoRoot = (git rev-parse --show-toplevel).Trim()
$taskRoot = Join-Path $env:TEMP ("alchemy-source-test-" + [guid]::NewGuid().ToString("N"))
$mediaEnv = Join-Path $taskRoot "media-runtime-venv"
$documentEnv = Join-Path $taskRoot "document-runtime-venv"
if (Test-Path -LiteralPath $taskRoot) { throw "Task temp path already exists; stop and choose a new unique path." }
if ($taskRoot.StartsWith($repoRoot, [System.StringComparison]::OrdinalIgnoreCase)) { throw "Task temp path must be outside the repository." }
New-Item -ItemType Directory -Path $taskRoot -ErrorAction Stop | Out-Null
if ((Test-Path -LiteralPath $mediaEnv) -or (Test-Path -LiteralPath $documentEnv)) { throw "Refusing to sync into a pre-existing environment." }
$env:UV_OFFLINE = "1"
$cachePath = (uv cache dir).Trim()
if ($LASTEXITCODE -ne 0) { throw "Cannot resolve configured uv cache; stop." }
Write-Output "Configured package cache: $cachePath"

$env:UV_PROJECT_ENVIRONMENT = $mediaEnv
Set-Location (Join-Path $repoRoot "services/media-runtime")
uv sync --locked
if ($LASTEXITCODE -ne 0) { throw "Locked offline sync failed; record BLOCKED_LOCAL_CACHE or BLOCKED_ENV and stop." }
uv run --locked python -B -m unittest discover -s tests -p "test_*.py" -q
if ($LASTEXITCODE -ne 0) { throw "media-runtime test suite failed; record output and stop." }
uv run --locked python -B -m unittest adapters.openmontage_audio.test_adapters adapters.openmontage_audio.test_segmented_music adapters.openmontage_audio.test_hyperframes_audio -q
if ($LASTEXITCODE -ne 0) { throw "media-runtime adapter tests failed; record output and stop." }

$env:UV_PROJECT_ENVIRONMENT = $documentEnv
Set-Location (Join-Path $repoRoot "services/document-runtime")
uv sync --locked
if ($LASTEXITCODE -ne 0) { throw "Locked offline sync failed; record BLOCKED_LOCAL_CACHE or BLOCKED_ENV and stop." }
uv run --locked python -B -m unittest discover -s tests -p "test_*.py" -q
if ($LASTEXITCODE -ne 0) { throw "document-runtime test suite failed; record output and stop." }
~~~

完成后记录 `$taskRoot` 与 `$cachePath` 绝对路径、exit code、依赖版本和 lock 中 package hashes；保留隔离环境直到证据通过审计，不自动删除。若 locked offline sync 因 cache miss 失败，P5 状态为 `BLOCKED_LOCAL_CACHE`，需请求新任务授权后再下载，不能将缺依赖误报成 parser 功能失败。若之后另有清理授权，只能先核对 `$taskRoot` 是本任务实际创建的唯一目录且位于 `$env:TEMP` 下，再单独精确清理；禁止递归删除 repo root、TEMP 父目录、项目 `.venv` 或任何预存 cache。

命令如果因本机 Python/uv/pnpm 不存在而无法执行，记 BLOCKED_ENV 和精确输出；不得安装全局包或改系统配置来绕开。按本地 python setup 文档单独处理授权。

## 5. 全量验证解释

- pnpm test/build/typecheck 是平台回归；不证明上游语义已迁移。
- Source fixture/conformance test 是来源行为复刻证据；不证明真实 Provider 运行。
- Runtime fake FFmpeg graph 是参数/输入图映射证据；不证明最终音频听感。
- MarkItDown clean lock install 是 packaging 证据；不证明恶意文档安全完备。
- 本资料包不授权真实 G02 生成或重新生成对照片。真实素材/Provider/声音听感须使用独立授权和新验收任务。
